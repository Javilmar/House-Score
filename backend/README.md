# Backend (pendiente)

Directorio reservado para la futura API + base de datos que sustituirá el
flujo actual de `frontend/datos/*.json` (ver
[.specify/memory/constitution.md](../.specify/memory/constitution.md),
principios II y V).

Todavía no hay código aquí a propósito: según la constitución del proyecto,
la migración a API + BBDD necesita pasar primero por un spec completo
(`/speckit-specify` → `/speckit-plan` → `/speckit-tasks`) antes de empezar a
implementar. Ver [GUIA-SPEC-KIT.md](../GUIA-SPEC-KIT.md) para el flujo
detallado.

Cuando el spec esté aprobado, este README se sustituye por la documentación
real del backend (stack elegido, cómo correrlo en local, cómo desplegarlo).
